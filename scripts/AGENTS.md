# `scripts/` — 검증·자동화 스크립트 규칙

이 폴더의 유틸리티 스크립트(`verify_report.py` 등)를 작성·수정할 때 적용되는 규칙입니다.

## 1. 구현 원칙
- **표준 라이브러리 전용**: `pip` 외부 패키지 의존성을 추가하지 말고 Python 표준 라이브러리만 사용합니다.
- **결정적 종료 코드**: 검증 통과 시 `0`, 하나라도 실패 시 `0`이 아닌 종료 코드(`1` 또는 `2`)를 반환합니다.
- **오프라인·온라인 분리**: CI 환경에서도 빠르게 실행될 수 있도록 오프라인 구조/인덱스 검증(`--offline`, `--check-index`)과 네트워크 기반 URL 검증을 명확히 분리합니다.

## 2. 회귀 테스트
- 스크립트 수정 후에는 반드시 기존 리포트(`reports/2026-11-15-am.html`, `reports/2026-11-16-am.html`)와 `reports/index.json`을 대상으로 실행해 기존 동작이 깨지지 않았는지 확인합니다.
