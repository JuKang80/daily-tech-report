#06 OmniDiff — 실제 오픈소스 diff 2,000건을 분석해 만든 Rust 기반 콘텐츠 인식 Git difftool [HN]

커뮤니티 반응 및 활용: 322포인트·97댓글에서 “기존 difftastic이나 delta보다 변경점이 훨씬 간결하게 나온다”는 칭찬과 함께, AGPLv3 라이선스가 Git 생태계 표준 채택에 제약이 될 수 있다는 실무 피드백과 와이드 터미널 side-by-side 뷰 요청이 이어졌습니다.

#07 Patchboard — 중단된 Docker·백업 실패를 맨 위에 띄워주는 홈서버 장애 우선 대시보드 [Reddit]

구체적 설명: 예쁜 아이콘만 나열하는 기존 홈랩 시작 페이지와 달리 Docker 소켓을 읽어 중단된 컨테이너, 가득 찬 스토리지 풀, 실패한 백업을 화면 최상단에 고정해 원클릭 복구 링크를 제공하는 50MB 경량 단일 컨테이너 대시보드(github.com/sourpatchdad/patchboard)입니다. Sonarr·Plex·Home Assistant·TrueNAS 등 약 68종 연동과 ntfy·Gotify·Discord 알림을 지원합니다.

커뮤니티 반응 및 활용: r/selfhosted 11월 1주차 신규 프로젝트 스레드에서 벽면 태블릿이나 전자잉크(e-ink) 디스플레이에 띄워 두고 홈서버 이상 징후만 즉시 파악·재시작·롤백하는 실용 운영 허브로 주목받았습니다.

#08 CarryCloud — Termux 설정 없이 안드로이드폰을 PHP 셀프호스팅 프라이빗 클라우드로 전환 [Reddit]

구체적 설명: 유휴 안드로이드 스마트폰을 별도 NAS나 VPS 임대 없이 개인 클라우드 서버로 바꾸는 오픈소스 안드로이드 앱(github.com/chenguangming/carry-cloud)입니다. 수동 Termux 환경 구성 없이 내장 PHP 런타임으로 kodbox 등 웹 파일 관리 앱을 바로 구동해 PC 브라우저에서 폰 로컬 저장소를 탐색·관리합니다.

커뮤니티 반응 및 활용: r/selfhosted 11월 2주차 신규 프로젝트 스레드에서 서랍 속 남는 안드로이드 기기를 저전력 개인 파일·문서 서버로 재활용하려는 홈서버 입문자들에게 간편한 진입 대안으로 호응을 얻었습니다.
