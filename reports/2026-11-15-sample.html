1. GitHub Trending 주요 저장소 (다음 정기 실행부터 Top 20 자동 반영)

#01 alibaba/open-code-review TypeScript · Code Review Agent

구체적 설명: 정적 규칙 기반의 결정적(deterministic) 파이프라인과 LLM 에이전트를 결합한 하이브리드 코드 리뷰 도구입니다. PR diff를 분석해 단순 린트 수준을 넘어 아키텍처·로직 결함을 라인 단위로 짚어줍니다.

활용 방안: GitHub Actions에 연동해 사람이 리뷰하기 전 1차 자동 리뷰어로 배치하면, 반복적인 코드 품질 점검 시간을 줄이고 핵심 설계 논의에 집중할 수 있습니다.

#02 GoogleChrome/modern-web-guidance-src Web · AI Agent Guidance

구체적 설명: AI 코딩 에이전트가 구식 패턴 대신 최신 웹 표준·성능·접근성 모범 사례를 따르도록 정리한 공식 가이드 및 참조 소스 저장소입니다.

활용 방안: 웹 프로젝트의 에이전트 규칙(AGENTS.md 또는 스킬)에 해당 가이드를 연결해 두면, 프론트엔드 UI 생성 시 최신 브라우저 API와 Core Web Vitals 기준에 맞는 코드를 얻기 쉽습니다.

#03 openai/codex-security Security · CLI / TypeScript SDK

구체적 설명: 저장소 내 보안 취약점을 탐지하고 실제 악용 가능성을 검증한 뒤 수정 패치까지 제안하는 보안 자동화 CLI 및 SDK입니다.

활용 방안: 릴리스 전 보안 점검 파이프라인이나 주간 스케줄 작업으로 돌려, 의존성·인증·입력 검증 취약점을 조기에 발견하고 패치 초안을 받아볼 수 있습니다.

#04 QwenLM/qwen-code AI Coding Agent · Terminal

구체적 설명: 터미널 환경에서 네이티브로 동작하며 코드베이스 탐색, 파일 편집, 명령 실행을 수행하는 오픈소스 AI 코딩 에이전트입니다.

활용 방안: 로컬 환경이나 사내 폐쇄망에서 오픈 웨이트 모델 기반 코딩 에이전트를 테스트하거나, 자동화 스크립트와 결합해 배치 리팩토링을 수행할 때 참고·도입할 수 있습니다.

#05 ChromeDevTools/chrome-devtools-mcp MCP · Browser Automation

구체적 설명: AI 에이전트가 Chrome DevTools 프로토콜에 직접 접근해 DOM 검사, 네트워크 추적, 콘솔 디버깅, 성능 프로파일링을 수행하도록 해주는 공식 MCP 서버입니다.

활용 방안: 프론트엔드 개발 중 발생하는 레이아웃 깨짐이나 API 응답 오류를 에이전트가 브라우저에서 직접 재현·진단하고 수정하게 만드는 워크플로에 바로 붙일 수 있습니다.
