커뮤니티 반응 및 활용: 252포인트·94댓글에서 Zulip, OpenCloud, Seafile, Syncthing의 실전 UX 비교와 “기업 환경에서 Outlook/Exchange의 ‘일정 한가함/바쁨(Free/Busy)’ 공유 기능을 대체하는 것이 가장 큰 장벽”이라는 현실적 경험담이 공유됐습니다.

#07 Backuparr — *arr 미디어 스택을 네이티브 API로 안전하게 백업하는 Docker 도구 [Reddit]

구체적 설명: Radarr·Sonarr·Prowlarr·Bazarr·Plex·Jellyfin 등 홈서버 미디어 스택을 백업할 때 쓰기 중인 SQLite DB가 깨질 수 있는 단순 볼륨 복사 대신, 각 앱의 공식 백업 API를 호출해 정합성 있는 스냅샷을 생성하고 Web UI와 rclone을 통해 로컬·Google Drive·OneDrive·Dropbox로 자동 적재하는 전용 Docker 컨테이너(rsaturns/backuparr)입니다.

커뮤니티 반응 및 활용: r/selfhosted 11월 3주차 신규 프로젝트 스레드에서 다수의 컨테이너 설정과 DB를 별도 스크립트 없이 웹 UI 원클릭으로 백업·복원하려는 홈랩 운영자들에게 실용적인 운영 도구로 주목받았습니다.

#08 Platypus — 로컬 Ollama·프론티어 모델을 칸반·크론으로 라우팅하는 셀프호스팅 에이전트 플랫폼 [Reddit]

구체적 설명: Docker Compose로 손쉽게 띄우는 MIT 라이선스 멀티테넌트 AI 에이전트 플랫폼(github.com/willdady/platypus)으로, 워크스페이스별 에이전트 격리, MCP 도구 연동, 칸반 보드 기반 에이전트 간 핸드오프, 크론·이벤트 기반 자동 실행을 지원합니다. 특히 반복·저비용 작업은 로컬 Ollama/vLLM으로, 고난도 작업은 프론티어 모델로 자동 라우팅하는 하이브리드 구조가 특징입니다.

커뮤니티 반응 및 활용: r/LocalLLaMA 프로젝트 쇼케이스 스레드에서 API 과금과 데이터 유출을 줄이면서도 다중 에이전트 워크플로우를 상시 가동하려는 로컬 LLM 사용자들의 셀프호스팅 스택 사례로 호응을 얻었습니다.
